description: Instructions for refactoring or fixing a bug found earlier
---

Whenever I ask you to refactor code or fix a bug, read this file.

Usually, when I ask you to fix a bug, I paste to the prompt some text copied over from elsewhere and ask you to refactor some code or to fix a bug. The pasted text often contains a earlier suggestion from you on how to fix it. Always carefully consider the suggestion on how to refactor/fix before implementing. Always go for only a very senior-like refactoring/change. And if there are several options, then list those shortly to me (succint explanations of why and why not for each) and we decide together which way to go.
